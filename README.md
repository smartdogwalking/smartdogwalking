# Maxwell D'Andrea

I build research tools and practical AI workflows, with an interest in making complex information traceable and useful.

## Selected projects

### [Umbern](https://github.com/smartdogwalking/umbern)

An evidence-backed research graph developed under the working name Follow the Money. The public showcase includes runnable graph-engine code, conservative entity resolution, provenance and validation, bounded traversal, a deterministic SEC parser, and seven offline tests.

The showcase uses synthetic data and excludes the private application, databases, credentials, and source caches. Development was AI-assisted; the repository documents the provenance and scope of the published code.

### [Ospirion Scout](https://github.com/smartdogwalking/ospirion-scout-showcase)

Deterministic components from a website-auditing application: bounded page selection, capture-quality assessment, and public-web URL validation. The source showcase includes a synthetic demo and ten offline tests; the prospect workspace and operational data remain private.

### [Humanizer Web](https://github.com/smartdogwalking/humanizer)

A focused Next.js rewriting interface around the humanization skill by [blader/humanizer](https://github.com/blader/humanizer). This fork adds the web application; the upstream skill and method remain attributed to their author.

Development is AI-assisted. Each published project explains its implementation, provenance, verification, and limitations. Full research, client-facing, and game-development work stays private where data or asset rights require it.
